# Linux

Linux installation, command line and server exercises on virtual machines.

## Projects

- [Linux Mint and Zorin OS in a virtual machine](linux-mint-and-zorin-os/README.md): installing two Linux distributions, comparing them and enabling the Simple System Monitor desklet on Linux Mint.
- [Installing utilities on Linux Mint](linux-utilities-nano-libreoffice/README.md): installing the Nano editor and LibreOffice, and creating, saving and editing a text file with Nano.
- [Web server with Apache, MariaDB and PHP on Linux Mint](lamp-web-server-apache-php/README.md): installing and testing a LAMP web server from the command line, locally and from a second virtual machine.
- [File sharing between Linux and Windows with Samba](samba-file-sharing/README.md): installing Samba on Linux Mint, creating a share and mapping it as a network drive on a Windows 11 client.
