# Technical support

Technical IT support projects and documentation.

## Projects

- [PC hardware upgrades](pc-hardware-upgrades/README.md): CPU, PSU, GPU, memory and hard drive replacements and additions on two PCs.
- [TeamViewer remote support exercise](teamviewer-remote-support/README.md): a remote support session between two virtual machines, including identity verification and running Windows updates.
- [Clock app quick guide](clock-app-quick-guide/README.md): a one-page A4 user guide with screenshots for a phone application, as PDF and the original Word document.
- [Lenovo ThinkPad T490 RAM upgrade](lenovo-ram-upgrade/README.md): adding an 8 GB SO-DIMM module to the free memory slot (8 GB to 16 GB), with the procedure, troubleshooting, verification and photos.
- [PowerShell: files and folders](powershell-files-and-folders/README.md): creating, copying, moving and removing files and folders, aliases, a first script and a session transcript.
- [Basic scripts in Windows and Linux](basic-scripts-windows-linux/README.md): the same system information script written as a Windows batch script, a PowerShell script and a Bash script.
- [Bootable USB media with Rufus, Ventoy and Media Creation Tool](bootable-usb-rufus-ventoy/README.md): an Ubuntu USB drive made with Rufus on Windows, a Windows 11 USB drive made with Ventoy on Ubuntu and a Windows 11 USB drive made with Microsoft's Media Creation Tool, with the Secure Boot error and its solution.
- [Connecting a laptop to a WiFi network](connect-laptop-to-wifi/README.md): a one-page A4 guide with screenshots for connecting a Windows 11 laptop to WiFi and checking the automatic IP and DNS settings, as PDF and the original Word document.
