# it_support

Projects and documentation related to the IT support role, grouped by topic. Each project has its own folder with a README, screenshots and, where relevant, the original files.

## Topics

- [Technical support](technical-support/README.md): PC hardware upgrades, remote support with TeamViewer and a user guide for a phone application.
- [Windows Server](windows-server/README.md): Active Directory, Group Policy, IIS and a Windows 11 domain client.
- [Linux](linux/README.md): Linux Mint and Zorin OS, command line utilities, a LAMP web server and Samba file sharing.
- [Networking](networking/README.md): IPv4 subnetting and Cisco Packet Tracer labs.
